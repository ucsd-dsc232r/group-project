## Project Objectives

This milestone-based group project emphasizes four main objectives:

1. **Time Management** – Meeting milestone deadlines, iterating on feedback, and coordinating team efforts across the quarter

## Data Requirements

Your dataset must be large enough to **require** distributed processing on SDSC Expanse. This is a Big Data course—working with data that fits comfortably on a laptop defeats the purpose.

**Minimum Data Size Requirements:**

| Tier | Raw Data Size | Description |
|---|---|---|
| **Minimum** | 10+ GB | Cannot fit comfortably in typical laptop RAM |
| **Recommended** | 50+ GB | Requires meaningful distributed processing |
| **Ambitious** | 100+ GB | Full HPC utilization |

*In industry, you'll work with datasets ranging from gigabytes to petabytes—this project prepares you for that reality.*

---

## Recommended Data Sources

Look for datasets that are large enough to require distributed processing:

- [Common Crawl](https://commoncrawl.org/) – Web crawl data (petabytes available)
- [NOAA Climate Data](https://www.ncei.noaa.gov/products) – Weather/climate records (used in course lectures)
- [NYC Taxi Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page) – Trip records (100+ GB available)
- [Reddit Comments Dataset](https://files.pushshift.io/reddit/) – Social media text data
- [OpenStreetMap](https://planet.openstreetmap.org/) – Geospatial data
- [Kaggle Public Datasets](https://www.kaggle.com/datasets) – Filter by size > 10GB
- [HuggingFace Datasets](https://huggingface.co/datasets) – ML-ready datasets
- [UC Irvine Machine Learning Repository](https://archive.ics.uci.edu/)
- [UCSD Social Science Data Collection](https://library.ucsd.edu/dc/collection/bb6255111r)
